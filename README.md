## 📝 프로젝트 개요

Cube Tic Tac Toe는 기존 2D 틱택토(삼목게임)를 3차원 큐브 형태로 확장한 게임입니다.

플레이어는 3x3x3 격자 공간(총 27칸)에서 O 또는 X를 번갈아 두며, 가로·세로·높이·대각선 등 **3차원상의 직선 3개 연결**을 목표로 합니다.

즉, 단순한 평면 승부가 아닌 입체적 전략과 공간 감각이 요구되는 게임입니다.

- **게임 방식**
    - 2명의 플레이어(또는 AI vs Player)가 번갈아 착수
    - 3차원 좌표 (x, y, z)에 자신의 말을 배치
    - 한 줄(3칸)을 먼저 연결하면 승리
    - 확장판으로 4x4x4도 가능하며, 이 경우 4칸을 먼저 연결하면 승리

## 🎯 프로젝트 목표

1. **전통 게임의 확장**
    - 단순한 2D 틱택토의 한계를 넘어, 더 깊은 전략성과 입체적 사고를 요구하는 3D 게임 구현
2. **시각적/인터랙티브 경험 강화**
    - 큐브 회전, 확대/축소 등 직관적인 카메라 조작을 통해 3차원 보드를 쉽게 탐색
3. **교육적 가치**
    - 게임을 통한 **공간 지각력 향상**과 **논리적 사고 훈련**
    - 학습용 또는 두뇌 퍼즐 게임으로 활용 가능
